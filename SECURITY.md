# Security Policy

## Supported versions

Security fixes are handled on the default branch and the latest deployable release line.

## Reporting vulnerabilities

Do not open a public issue for suspected vulnerabilities, secrets, tokens, exploit details, or production-like data.

Report vulnerabilities through GitHub security advisories:
https://github.com/krotname/SmartLinks/security/advisories/new

Include:

- affected version or commit,
- reproduction steps,
- relevant request/redirect payloads with secrets redacted,
- impact assessment,
- suggested mitigation if available.

The maintainer aims to acknowledge valid reports within 48 hours and provide a remediation timeline after the impact is confirmed.
