# Управление ссылками 0.1.0

Публичные ссылки: https://n-0.ru/код. Создание: https://links.n-0.ru/.

Управление использует отдельную сессию Spring Security и CSRF, требует HTTPS и точный host.
Задайте SMARTLINKS_OWNER_USERNAME и SMARTLINKS_OWNER_PASSWORD_HASH (DelegatingPasswordEncoder, например bcrypt).
Пустые значения закрывают вход. Пароль и API-ключ в браузер не передаются.
За доверенным прокси задайте SERVER_FORWARD_HEADERS_STRATEGY=framework; прокси обязан
перезаписывать Forwarded/X-Forwarded-* и ограничивать доступ к управлению точным поддоменом.
TZ=Europe/Moscow задаёт часовой пояс DateRange, поля интерфейса используют локальное время МСК.

POST /manage/api/smartlinks возвращает 201 с id и url. GET /manage/api/smartlinks/{id}
читает сохранённое определение. Обе операции вызывают существующий SmartLinkService.
Правила и порядок хранятся без преобразования: первое совпадение, последний запасной адрес.
Обычная ссылка содержит только запасное правило. Занятый код даёт 409.
Общий валидатор блокирует служебные имена, в том числе для прежнего POST /api/smartlinks.
SMARTLINKS_RESERVED_IDS позволяет добавить зарезервированные имена через запятую.

Прежние GET /s/{id} и POST /api/smartlinks с X-API-Key сохраняются.
Внешняя маршрутизация публикует только /s/ на основном домене и /manage/ на поддомене;
Redis, actuator и прежний API доступны только внутри инфраструктуры.

Редактирование, удаление и статистика в выпуск не входят.
